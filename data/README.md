# data/

Put your contact files here (for example `contacts_clean.xlsx`).

Everything in this folder except this README and `.gitkeep` is **ignored by git on purpose**:
the files contain personal data (names and work email addresses of other people) and must not be
pushed to GitHub. Upload files through the **Contacts → Import** page; the app keeps its own copy of
accepted uploads in `data/uploads/` (also git-ignored).
